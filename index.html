Pick your apps

Select the apps you want, generate the script, run it. No installer needed.

What it does

Cross-platform — Windows, macOS, and Linux with one tool
Batch install — select dozens of apps and install them all at once
Open source — MIT licensed, no telemetry, no tracking
Native feel — lightweight Qt desktop app that fits your OS
Auto-updates — downloads and installs new versions from inside the app
Private — nothing is collected, sent, or sold. ever.
